# FC Draft 2027 UT

A football card draft, squad builder, card pack store, and live match simulation web application inspired by Ultimate Team.

## Features

- **Draft Mode**: Pick from multiple tactical formations (4-4-2, 4-3-3, 4-2-3-1, 3-5-2, etc.), select players for each slot across 5 randomized choices with rarity weights, build team chemistry, and advance straight to matches.
- **Interactive Squad Builder**: Real-time tactical pitch with dynamic positioning, chemistry score calculation (0 to 33 diamonds matching club, league, and nation links), formation selector, and substitute bench.
- **My Club (Collection)**: Search and filter collected player cards by position, rarity (Bronze, Silver, Gold, Elite), club, and nation with detailed attribute view.
- **Gold Packs Store**: Purchase packs for 500 coins to unbox players with authentic probability rolls (Bronze 55%, Silver 30%, Gold 12%, Elite 3%) and celebratory animations.
- **Match Simulator**: Poisson-based match engine simulating live 90-minute games with commentary (goals, chances, saves, yellow & red cards) and coin payouts (+500 for win, +300 for draw, +200 for loss).
- **Settings & Onboarding**: 6-step interactive tutorial and full progress reset options.
